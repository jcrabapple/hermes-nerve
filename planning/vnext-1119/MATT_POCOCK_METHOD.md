# Matt Pocock Skills Applied

This implementation package was shaped using the live `mattpocock/skills` repository patterns retrieved from GitHub on 2026-09-18.

- `to-spec`: synthesize existing discussion without re-interviewing; specify problem/solution/user stories/implementation/testing/out-of-scope.
- `wayfinder`: name the destination, record resolved architecture decisions, keep remaining fog explicit.
- `to-tickets`: tracer-bullet tickets, one verifiable slice per ticket, explicit blocking edges and ready frontier.
- `codebase-design`: small stable interfaces/deep modules; tests and callers cross the same seams.
- `prototype`: throwaway logic prototype to settle the asynchronous state model before production.
- `tdd`: red → green vertical slices, behavior through agreed public seams.
- `implement-spec` (in progress): execute the ticket graph from the ready frontier with parallel implementers/worktrees and one integration PR.
- `code-review`: final independent Standards and Spec axes.

No MegaMCP was used to build this package.
